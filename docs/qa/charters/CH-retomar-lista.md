# CH-retomar-lista: Retomar tarefas salvas

```yaml
charter:
  id: CH-retomar-lista
  mission: Conteúdo estado e ordem confirmados sobrevivem à reabertura
  mode: charter-with-tour
  persona:
    name: Pessoa retomando
    device: desktop
    network: wifi-fast
    locale: pt-BR
  journey: J-retomar-lista
  scenarios: [DATA-reabrir-lista]
  tour: Interrupt Tour
  time_box_minutes: 60
  guidance:
    must_try:
      - Abrir um diretório isolado
      - Reabrir o mesmo diretório
      - Rascunho abandonado não é persistido; última ação confirmada reaparece
    must_avoid:
      - Usar dados reais ou acessar a janela de outro aplicativo
      - Afirmar Pass sem observação na janela e evidência de reabertura
```
